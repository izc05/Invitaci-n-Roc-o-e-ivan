# Invitación Rocío e Iván

Invitación web móvil basada en la V10.

## Publicación

El repositorio incluye un workflow de GitHub Pages. Cada cambio en `main` vuelve a publicar automáticamente la web.

## Estructura

- `index.html` — invitación
- `assets/images/` — imágenes optimizadas WebP
- `assets/audio/music.mp3` — música
- `.github/workflows/pages.yml` — despliegue GitHub Pages

La música comienza tras el primer toque en **Abrir invitación**, para cumplir las restricciones de reproducción automática de Safari/iPhone.
